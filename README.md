# Biblioteca en Python

## Requisitos

- Python 3.10 o superior, necesario para utilizar `match`.
- Git, si se desea clonar el repositorio.
- No requiere instalar bibliotecas externas.

## Instalación

Clona el repositorio y entra en su carpeta:

```bash
git clone https://github.com/AitorYusteConejos/Biblioteca_Python-Aitor-Yuste.git
cd Biblioteca_Python-Aitor-Yuste
```

También puedes descargar el repositorio como ZIP desde GitHub y descomprimirlo.

## Ejecución

Ejecuta siempre el programa desde la carpeta que contiene `main.py`.

### Windows

Comprueba la versión de Python:

```powershell
py -3.10 --version
```

Inicia la aplicación:

```powershell
py -3.10 main.py
```

También puedes utilizar `python main.py` si el comando `python` corresponde a una versión 3.10 o superior.

### Linux

Comprueba la versión de Python:

```bash
python3 --version
```

Debe ser Python 3.10 o superior. Inicia la aplicación:

```bash
python3 main.py
```

Si tienes varias versiones instaladas y quieres utilizar específicamente Python 3.10:

```bash
python3.10 main.py
```

## Funcionalidades

- Listar todos los libros y los disponibles.
- Buscar libros por parte del título, sin distinguir mayúsculas y minúsculas.
- Dar de alta libros y socios.
- Realizar préstamos y devoluciones.
- Consultar los socios que tienen un préstamo.
- Guardar los datos y recuperarlos en la siguiente ejecución.
- Registrar la actividad en `log.txt`.
